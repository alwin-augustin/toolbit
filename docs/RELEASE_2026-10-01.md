# Web/PWA release — 1 October 2026

Native runtime, packaging, releases and retained desktop build artifacts have been retired. Cloudflare Pages remains the only deployment target. Workspace documents and recipes are versioned and distinct; unsaved data is session-only, and named workspaces exclude payload unless explicitly selected. Sensitive tool payloads always stay excluded. See the implementation plan, privacy ADRs and runtime/storage inventory for details.
