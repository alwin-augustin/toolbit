Status pill with a glowing leading dot (or icon) — a Toolbit signature for trust/status: "No network calls made", offline, valid/invalid.

```jsx
<StatusPill tone="success" icon={<ShieldCheckIcon />}>No network calls made</StatusPill>
<StatusPill tone="success">Valid JSON</StatusPill>
<StatusPill tone="danger">Invalid</StatusPill>
```

Tones: success, warning, danger, neutral, primary.
