Square icon-only button for toolbar actions — copy, clear, theme toggle, overflow menu. Always pass a `title` for accessibility.

```jsx
<IconButton title="Copy output"><CopyIcon /></IconButton>
<IconButton variant="outline" title="Clear"><TrashIcon /></IconButton>
```

Variants: `ghost` (default, subtle hover lift), `outline`, `solid` (blue). Sizes: `sm` (28px), `default` (36px), `lg` (44px).
