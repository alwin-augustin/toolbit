Primary action button for Toolbit — sentence-case labels, blue primary fill, optional leading/trailing Lucide icons.

```jsx
<Button>Format</Button>
<Button variant="outline">Minify</Button>
<Button variant="ghost" size="sm" iconLeft={<TrashIcon />}>Clear</Button>
<Button variant="destructive">Delete workspace</Button>
```

Variants: `default` (blue CTA), `secondary` (filled neutral), `outline`, `ghost` (toolbar actions), `destructive`, `link`. Sizes: `sm` (32px), `default` (36px), `lg` (44px). Keep labels short and verb-first.
