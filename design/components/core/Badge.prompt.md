Compact status/count badge with soft tinted fills. Used for tool counts, "Saved"/"Preset" tags, validity, "Local-only".

```jsx
<Badge>8 tools</Badge>
<Badge tone="success">Valid</Badge>
<Badge tone="warning" variant="outline">Large file</Badge>
<Badge tone="primary">PWA</Badge>
```

Tones: `neutral`, `primary`, `success`, `warning`, `danger`. Variants: `soft` (default), `outline`, `solid`.
